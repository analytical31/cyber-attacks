# Cyber Attacks Analysis Dashboard</br>
## Project Overview</br>
This project presents a comprehensive Cyber Attacks Analysis Dashboard developed using SQL, Python, and Power BI to analyze login activities, identify failed authentication attempts, monitor user behavior, and uncover potential cybersecurity threats.</br>


## Objectives</br>
Monitor successful and failed login attempts.</br>
Analyze login activities across different countries.</br>
Identify users with high login frequencies.</br>
Track authentication success rates.</br>
Detect unusual access patterns that may indicate cyber threats.</br>
Provide interactive filtering for detailed investigation.</br>
